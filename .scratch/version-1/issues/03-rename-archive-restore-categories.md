# 03: Rename, archive and restore Categories

**What to build:** On the Categories screen the student can rename a Category, archive it, and restore it. Categories are never deleted: an Archived Category is hidden from the main list but kept, with all its history, in an "Archived" section, from where it can be restored.

**Blocked by:** 02 (Chinese / English language switch)

**Status:** ready-for-agent

- [ ] The student can rename a Category; an empty name can't be saved
- [ ] The student can archive a Category; it moves out of the active list into an Archived section
- [ ] The student can restore an Archived Category; it returns to the active list
- [ ] There is no way to delete a Category
- [ ] Renaming, archiving and restoring are kept after reopening the app
- [ ] Tests cover rename, archive and restore
- [ ] All new screen text exists in 中文 and English
