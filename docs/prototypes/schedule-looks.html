Personal Schedule Looks

Your version 1 app in four looks, with the same features in each. Tap a circle to tick an Action, tap a ticked one to untick, and try the 设置 tab to add or archive Categories. The data is an example Monday.

App language
A

原生清爽 Native

Looks like Apple's own apps: grouped lists, round ticks and a jade green accent. Familiar from day one.

Build effort: easiest, mostly built-in SwiftUI lists
B

田字格 Practice book

Inspired by character practice paper. A finished Action gets a red 完 seal, like a teacher's stamp.

Build effort: medium, custom header boxes and seal
C

地铁线 Metro line

Your day as a metro line. Each Category is a line colour and each Action a station, with bilingual signs like the metro in China.

Build effort: harder, custom timeline drawing
D

打卡 Check-in

Big 打卡 buttons and a Chinese-minutes ring at the top, so today's practice is the first thing you see.

Build effort: medium, custom cards and a ring

To choose, reply in the terminal with A, B, C or D. You can also mix them, for example B, but with D's summary ring. The ring in D only adds up today's Chinese minutes; the full Progress Tracker comes in a later version.
